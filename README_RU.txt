AIS.STORE MANAGER 2.0 — УСТАНОВКА НА IPHONE БЕСПЛАТНО

ЧТО В ПАКЕТЕ
- index.html — приложение
- manifest.json — параметры установки на главный экран
- sw.js — кэширование файлов для повторного/офлайн-открытия
- icons/ — иконки приложения

БЕСПЛАТНАЯ ПУБЛИКАЦИЯ ЧЕРЕЗ GITHUB PAGES
1. На iPhone или компьютере откройте https://github.com и создайте аккаунт/войдите.
2. Нажмите + → New repository.
3. Название репозитория: ais-store-manager (латиницей).
4. Выберите Public и нажмите Create repository.
5. В репозитории нажмите Add file → Upload files.
6. Распакуйте ZIP и загрузите СОДЕРЖИМОЕ папки AisStoreManagerPWA, а не сам ZIP. В корне должны лежать index.html, manifest.json, sw.js и папка icons.
7. Нажмите Commit changes.
8. Откройте Settings → Pages.
9. В разделе Build and deployment выберите Deploy from a branch.
10. Branch: main; folder: /(root); нажмите Save.
11. Подождите 1–5 минут. На странице Pages появится ссылка вида:
   https://ВАШ-ЛОГИН.github.io/ais-store-manager/
   Это пример формата, замените ВАШ-ЛОГИН на ваш GitHub username.

УСТАНОВКА НА IPHONE
1. Откройте готовую GitHub Pages ссылку именно в Safari.
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх).
3. Выберите «На экран Домой» (при необходимости прокрутите список).
4. Включите «Открывать как веб-приложение», если такой переключатель показывается, и нажмите «Добавить».
5. Запускайте Ais.Store с новой иконки на главном экране.

ВАЖНЫЕ ОГРАНИЧЕНИЯ
- Публикация на GitHub Pages публичная: не добавляйте в приложение конфиденциальные сведения, которые нельзя хранить в публично размещённом клиентском коде. Данные, введённые в приложении, сохраняются локально в браузере на конкретном устройстве и не синхронизируются с другими устройствами.
- Экспортируйте резервную копию регулярно кнопкой «Экспорт данных» и храните JSON-файл в безопасном месте.
- Если очистить данные Safari, локальные записи приложения могут быть удалены.
- Это веб-приложение, а не приложение из App Store.
